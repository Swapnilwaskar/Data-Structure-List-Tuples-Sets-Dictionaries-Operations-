# Python Product Catalog Tasks

This project contains 4 Python files that demonstrate common data structures in Python: lists, tuples, sets, dictionaries, and combined data processing.

## Project Files

- `Task1.py` – Product collections using lists and tuples
- `Task2.py` – Unique categories using sets
- `Task3.py` – Product pricing using dictionaries
- `Task4.py` – Combined operations using list of tuples and category grouping

## Learning Objectives

These tasks cover:

- Creating and modifying lists
- Working with tuples and converting them to lists
- Using sets to remove duplicates and check membership
- Storing product prices in dictionaries
- Performing calculations like average, min, and max values
- Combining related data from multiple structures
- Grouping products by category

## How to Run

Open a terminal in the project folder and run any task file individually:

```bash
python Task1.py
python Task2.py
python Task3.py
python Task4.py
```

## Example Concepts Covered

### Task 1: Product Collections
- Create a product list
- Create a sample tuple for a product
- Access the second and last item in the list
- Append new product entries
- Update tuple values by converting to a list

### Task 2: Categories
- Create a category list and convert it to a set
- Add categories while avoiding duplicates
- Check if a category exists in the set
- Count unique categories

### Task 3: Product Pricing
- Store products and prices in a dictionary
- Add and update product prices
- Calculate average price
- Find the most and least expensive product

### Task 4: Combined Operations
- Combine products, prices, and categories into a list of tuples
- Group products by category
- Determine which category contains the most products

## Notes

This project is a beginner-friendly Python exercise designed to practice core Python data structures and basic operations.
